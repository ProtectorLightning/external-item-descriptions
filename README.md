## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Item Details** | Full description of every item's effect and behavior in-game |
| **Synergy Notes** | Community-documented synergies shown alongside base descriptions |
| **Mod Support** | Automatically shows descriptions for modded items via API |
| **Configurable Display** | Choose font size, position and which info fields are shown |
